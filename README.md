# Lattice Exchange Asset Registry

Public registry of asset provenance cards and license documents referenced by
listings in the Lattice Exchange storefront.

Index:

- `registry/datasets/halcyon-sentence-grade-atlas.md` - dataset card
- `registry/datasets/web-attenuation-archive.md` - dataset card
- `registry/models/oxley-a3-lite.md` - model card
- `licenses/oxley-a3-lite-license.txt` - full license document for the model above

The registry mirror of the storefront program is maintained by the licensing
desk. Cards are the authoritative source for license identifiers; storefront
listings repeat the identifiers only as convenience copies.
